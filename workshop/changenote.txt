0.3.0: one-click install.
KeelSetup.exe in Keel's Workshop folder finds Sea Power, adds BepInEx if the game has none, installs the starter file and sets another loader's preloader aside, so only one loader is active. Restore, in the same window, undoes exactly what it changed.
Nothing changes for players who already have Keel set up; the mod loader itself is the same as 0.2.0.
Windows may say "unknown publisher" because the file is not signed yet.
Run on a clean copy of the game on the 3D globe public beta (build 261107); 0.8.7 not run.
