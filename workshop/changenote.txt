0.4.0: ready for Sea Power 0.9.0, plus Restart, Reload and Send report.
The game no longer lists Keel as "not declared to be compatible", and 0.9.0 players get its updates from the Workshop.
Mods menu: the game's reload dialog gets a Restart button (saves your mod list, closes the game and starts it again). Its Reload now also starts code mods you switched on and takes switched-off ones out as far as the running game allows; a full Restart is the clean way.
Report window (Ctrl+Shift+K): Restart the game (two clicks).
Crash and report windows: Send report sends your logs to the R.A.T.S. developer in one click, with your Windows user name removed from every path; you see the file list and confirm first.
Run in the game on 0.9.0 (build 261111): start-up with 17 mods, Reload and Restart. Send report: sent from the developer PC, its window not yet clicked in the game.
